# Manual Linguistic Annotations

This directory contains the manually annotated
NSMC review sample used for linguistic subgroup
analysis in NLP Homework 2.

- annotation_completed.csv: Human annotations for
  negation, slang/idioms, and sarcasm/irony.
- annotation_key.csv: Review IDs, predictions,
  sampling strata, and sampling weights.

The annotation sample contains 100 reviews,
stratified by the prediction outcomes of the
seed-42 classifiers.
